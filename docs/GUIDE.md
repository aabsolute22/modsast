# Гайд по End City Finder

Мод находит все города края (и корабли с элитрами) по нескольким найденным городам и
обсидиановым столбам на главном острове. Ставится только тебе, серверу и другу он не нужен
(другу нужен, только если хотите делиться находками).

## 1. Установка

1. Нужны Fabric Loader 0.20.1 или новее для Minecraft 26.2, Fabric API для 26.2 и Java 25.
2. Скачай мод: github.com/aabsolute22/modsast → вкладка **Actions** → последний зелёный запуск
   **build** → внизу **Artifacts** → `endcityfinder` (нужен вход в GitHub).
3. Распакуй zip и положи `endcityfinder-0.1.0.jar` в папку `mods`.

## 2. Быстрый старт

1. **Пилоны.** Зайди в энд и подлети к центральному острову, чтобы прогрузились все 10
   обсидиановых столбов. Слева сверху появится `пилоны 10/10`.
2. **Города.** Улетай через гейтвей и найди город края. Пролети над ним и подожди пару
   секунд: в чате появится `[ECF] Город #1: чанк … поворот …`.
   Если сообщения нет, зайди в нижний зал главной башни (первый этаж со входом) и нажми `L`.
3. **Ещё два города.** Повтори для двух других. Обычно хватает трёх.
4. **Ожидание.** Перебор стартует сам: слева сверху `перебор N%`, это 10–60 секунд.
   Когда в чате появится `[ECF] сид энда …`, всё готово.
5. **Поиск.** Сверху по центру стрелка к ближайшему городу, под ней метры и координаты.
   Вторая стрелка висит в мире под прицелом. Над городами рядом стоят рамки и лучи,
   дальние города видны столбиками на горизонте.

## 3. Только корабли

* `/ecf ships` оставляет только города с кораблями: стрелка, маркеры, карта и список.
  Повторная команда возвращает все города.
* У города с кораблём рядом висит жёлтый маркер `корабль, элитры` прямо над кораблём.
* Залутанные города исчезают сами: город считается залутанным, когда ты побывал внутри
  его границ или в 40 блоках от основания. Показать их снова: `/ecf looted`.

## 4. Игра с другом

У друга тоже должен стоять мод.

1. Ты: `/ecf party add <ник друга>`. Друг: `/ecf party add <твой ник>`.
2. Готово. Когда у одного находится сид, он сам уходит второму личным сообщением.
   Залутанные города тоже рассылаются, и у обоих они пропадают с экрана.
3. Отправить вручную: `/ecf share` (всем друзьям) или `/ecf share <ник>`.
4. Если сид прислал кто-то не из друзей, в чате будет кнопка `[принять]` (или `/ecf accept`).

Служебные сообщения мод у получателя прячет из чата. Но это обычные `/msg`, так что админ
сервера видит их в логах.

## 5. Если сервер поменял соль городов

На Paper и Spigot админ может поменять `seed-endcity` в `spigot.yml`. Тогда с обычной
солью ничего не сойдётся, и мод сам переключится на её вычисление:

* слева сверху будет `вычисляю соль сервера`, это до пары минут;
* нужно хотя бы 3 города, найденных пролётом или кнопкой `L` (так мод знает их поворот).
  Чтобы соль определилась точно, лучше 6–7 городов;
* пока вариантов соли несколько, показываются только общие для всех вариантов города.
  Полетай ещё или найди город, и варианты отсеются;
* если соль известна, её можно ввести: `/ecf salt <число>`. Сброс: `/ecf salt reset`.

## 6. Карта

`J` открывает карту энда: фон это биомы, квадраты это города (жёлтые с кораблём),
белая стрелка это ты. Колесо мыши меняет масштаб, ЛКМ перетаскивает карту,
ПКМ по городу делает его целью для стрелки.

## 7. Клавиши и команды

| | |
| --- | --- |
| `J` | карта |
| `K` | маркеры в мире вкл/выкл |
| `L` | добавить город рядом (стоя в нижнем зале) |
| `/ecf status` | что мод знает и что делает |
| `/ecf list [n]` | ближайшие города, номер кликабельный |
| `/ecf target <n>` / `/ecf target nearest` | цель для стрелки |
| `/ecf ships` | только города с кораблями |
| `/ecf looted` | показывать или скрывать залутанные |
| `/ecf visited <n>` | отметить залутанным или снять отметку |
| `/ecf chunk <cx> <cz> [0/90/180/270]` | город по номеру чанка |
| `/ecf add <x> <z>` | город по примерным координатам |
| `/ecf cities`, `/ecf remove <id>` | найденные города, удалить ошибочный |
| `/ecf pillars`, `/ecf pillar <номер> <высота>` | столбы, ручной ввод |
| `/ecf party add/remove <ник>`, `/ecf share [ник]`, `/ecf accept` | игра с другом |
| `/ecf salt [число/reset]` | соль городов |
| `/ecf seed <число>` | если сид уже известен |
| `/ecf radius <блоки>` | радиус показа (по умолчанию 5000) |
| `/ecf markers`, `/ecf arrow`, `/ecf hud` | части интерфейса вкл/выкл |
| `/ecf reset confirm` | стереть всё по этому серверу |

## 8. Если что-то не так

* **`нужно больше городов`**: найди ещё один город.
* **`противоречие`**: открой `/ecf cities` и удали подозрительный город через
  `/ecf remove <id>`. Чаще всего это город, вписанный руками с ошибкой.
* **Город не засчитался**: зайди в нижний зал главной башни и нажми `L`. Если пишет
  `неточно`, основание могли разломать, город всё равно учитывается, но слабее.
* **Столб не считался**: его могли сломать. Посмотри `/ecf pillars` и впиши высоту бедрока
  на верхушке: `/ecf pillar <номер> <высота>`.
* Всё сохраняется отдельно для каждого сервера, можно выйти и продолжить потом.
