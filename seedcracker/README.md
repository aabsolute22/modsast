# Seed Cracker

Клиентский Fabric мод для Minecraft Java **26.2**. Вычисляет сид мира на любом сервере по тому,
что клиент и так получает (структуры, биомы, хэш сида), а потом ищет всё в **верхнем мире и незере**:
структуры, биомы, крепости с порталом в энд, слайм-чанки. До цели ведёт красивая анимированная
линия, на экране компас, есть экран поиска и карта мира. Энда тут нет, для него отдельный мод
End City Finder в корне репозитория.

Мод ничего не отправляет на сервер, он только смотрит на прогруженные чанки.

Гайд для игроков: **[docs/GUIDE.md](docs/GUIDE.md)**. ТЗ и как это устроено: **[docs/SPEC.md](docs/SPEC.md)**.

## Установка

1. Fabric Loader 0.20.1+, Fabric API для 26.2, Java 25.
2. `seedcracker-*.jar` в папку `mods`. Собранный jar лежит в артефактах GitHub Actions
   (workflow `seedcracker`, артефакт `seedcracker`), или собрать самому: `./gradlew -p seedcracker build`,
   файл появится в `seedcracker/build/libs/`.

## Коротко

* Просто играй. Мод сам замечает деревни, пирамиды, храмы в джунглях, хижины ведьм, иглу, корабли,
  руины, разрушенные порталы, монументы, древние города, руины троп, камеры испытаний, клады,
  а в незере адские крепости, бастионы-мосты и порталы. В чате появляется `[SC] Нашёл: …`.
* Как только данных хватает, перебор стартует сам (слева сверху `перебор N%`). Остальные 16 бит сида
  берутся из хэша, который сервер шлёт при входе, а если сервер его подменил, то из биомов.
* `B` поиск: пишешь «деревня», «вишнёвая роща», «крепость», кликаешь результат, и до него тянется линия.
* `M` карта биомов с отмеченными структурами, `V` линии и метки вкл/выкл.
* В одиночной игре сид берётся сразу из сохранения, а на своём сервере можно `/sc seed <число>`.

## Команды

| Команда | Что делает |
| --- | --- |
| `/sc`, `/sc status` | что найдено и что делает перебор |
| `/sc find <тип> [n]` | ближайшие структуры, клик ведёт к ней |
| `/sc biome <биом>` | ближайшие места биома |
| `/sc target <x> <y> <z>` / `clear` | своя цель для линии и компаса |
| `/sc track <тип>` | показывать этот тип в мире (метки, рамки, линии к ближайшим) |
| `/sc structures`, `/sc remove <id>` | найденные структуры, удалить ошибочную |
| `/sc add <тип> <чанкX> <чанкZ> [поворот]` | добавить структуру руками по стартовому чанку |
| `/sc seed [число / clear]` | показать или задать сид |
| `/sc crack` / `/sc cancel` | запустить долгий перебор / остановить |
| `/sc radius <блоки>` | радиус поиска (по умолчанию 3000) |
| `/sc slime`, `/sc lines`, `/sc markers`, `/sc hud`, `/sc visited` | переключатели |
| `/sc gui`, `/sc map` | экран поиска и карта |
| `/sc reset confirm` | стереть всё по этому миру |

Данные лежат в `config/seedcracker/worlds/<сервер или мир>.json`, настройки в `config/seedcracker/settings.json`.

## Как это работает (кратко)

* Расстановка структур (`random_spread`) зависит только от младших 48 бит сида. Каждая найденная
  структура с точным стартовым чанком даёт 9–10 бит, поворот ещё 2.
* Перебор 2^48 не нужен: у пирамид, храмов, иглу, хижин и аванпостов делитель 24, у кораблей 20,
  у руин 12, у деревень 26, и смещение выдаёт младшие биты. Сначала отсеиваются младшие 20 бит,
  потом середина, а старшие 13 бит не перебираются, а вычисляются напрямую из кладов (`nextFloat < 0.01`),
  древних городов и сравнений по модулю для остальных структур. С двумя храмами это доли секунды,
  с деревнями и кораблями секунды, только по незеру около 10 минут на 4 ядрах.
* Верхние 16 бит: SHA-256 от сида приходит клиенту при входе (`BiomeManager.obfuscateSeed`), это
  65536 вариантов и миллисекунды. Без хэша мод перебирает 65536 вариантов по биомам из прогруженных
  чанков, считая только шесть шумов климата (около 15 секунд).
* Поиск и карта считаются настоящим кодом генерации 26.2 (реестры загружаются из ванильного датапака
  внутри игры), поэтому результат совпадает с `/locate`: с проверкой биомов, высоты и исключений.

## Проверка

* `CrackerTest`: ядро без Minecraft на синтетических данных.
* `VanillaTest`: сверка с настоящим кодом 26.2 (расстановка, частоты, зоны исключения, хэш, повороты
  стартовых кусков, геометрия шаблонов, климат, слайм-чанки) и сквозной взлом мира: ванильные
  структуры → сид структур → хэш → тот же сид, а также поиск без хэша по биомам.
* `SeedCrackerGameTest` (workflow `seedcracker`, job `client-gametest`): настоящий клиент и сервер
  с известным сидом, бот облетает структуры, мод сам их находит и взламывает сид, поиск сверяется
  с правдой, скриншоты линий, экрана поиска и карты печатаются в лог.

## Ограничения

* Датапаки с другой генерацией и Paper/Spigot с изменёнными солями (`seed-village` и т.п. в
  `spigot.yml`) ломают вычисление.
* Аванпосты, бастионы кроме моста и особняки пока не распознаются по блокам (стартовый кусок у них
  невидим), их можно добавить руками через `/sc add`.
