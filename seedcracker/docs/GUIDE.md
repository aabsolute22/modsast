# Гайд по Seed Cracker

Мод сам вычисляет сид мира по тому, что ты видишь, и потом находит любые структуры и биомы
верхнего мира и незера. Ставится только тебе, серверу ничего не нужно.

## 1. Установка

1. Fabric Loader 0.20.1 или новее для Minecraft 26.2, Fabric API для 26.2 и Java 25.
2. github.com/aabsolute22/modsast → вкладка **Actions** → последний зелёный запуск **seedcracker** →
   внизу **Artifacts** → `seedcracker` (нужен вход в GitHub).
3. Распакуй zip и положи `seedcracker-0.1.0.jar` в папку `mods`.

## 2. Как получить сид

1. Зайди на сервер и просто играй или летай. Слева сверху строка `SC · …` показывает, что мод знает.
2. Мод сам замечает структуры в прогруженных чанках, в чате появляется `[SC] Нашёл: …`.
   Больше всего помогают **пирамиды, храмы в джунглях, хижины ведьм, иглу** (по одной хватает почти
   на треть дела), потом **корабли, подводные руины, клады**, потом **деревни, порталы, древние
   города, камеры испытаний, руины троп**. В незере **адские крепости, бастионы-мосты, порталы**.
3. Как только данных хватает, начинается перебор: `перебор 42% · осталось ~20 с`.
   Обычно это 2–6 структур и от долей секунды до минуты. Только по незеру перебор долгий
   (около 10 минут на 4 ядрах), мод спросит: напиши `/sc crack`, чтобы начать.
4. Когда сид найден, в чате будет `[SC] Сид найден: …` (нажми на число, чтобы скопировать).

В одиночной игре всё готово сразу, сид берётся из мира. Если сид известен, `/sc seed <число>`.

## 3. Поиск (клавиша B)

* Сверху строка поиска: «деревня», «пустыня», «крепость», «вишнёвая роща», «грибной»,
  «слайм» и так далее, работает и по-английски.
* Слева категории: структуры текущего измерения, слайм-чанки и все биомы. Справа ближайшие
  находки с расстоянием, стороной света и координатами.
* **ЛКМ** по результату: это твоя цель. До неё тянется линия, сверху компас.
  **ПКМ**: отметить посещённым (или удалить свою находку в «Найденные тобой»).
* Кнопка «Показывать в мире» включает для типа постоянные метки: рамки структур, маяки и тонкие
  линии к двум ближайшим. Для адских крепостей отдельно подсвечиваются спавнеры ифритов.
* Для крепости (портал в энд) цель сама уточняется до комнаты с порталом.

## 4. Линии и метки

* Линия к цели идёт дугой от тебя, по ней бегут световые импульсы в сторону цели, цвет зависит от
  типа структуры. У цели луч в небо, кольцо и подпись с расстоянием.
* Если цель дальше прорисовки, линия заканчивается ромбом на горизонте в её сторону.
* `V` выключает и включает всё сразу. `/sc lines`, `/sc markers` по отдельности.

## 5. Карта (клавиша M)

Фон это биомы по сиду, квадраты это структуры (отслеживаемые типы, иначе деревни и крепости),
белые рамки это то, что нашёл ты, стрелка это ты. Колесо меняет масштаб, ЛКМ тащит,
**ПКМ** по структуре делает её целью, ПКМ по пустому месту ставит туда точку.

## 6. Команды

| | |
| --- | --- |
| `B` / `M` / `V` | поиск / карта / линии вкл-выкл |
| `/sc status` | что найдено, сколько бит, есть ли хэш сида |
| `/sc find <тип> [n]` | ближайшие, клик по строке ведёт туда |
| `/sc biome <биом>` | ближайшие места биома |
| `/sc track <тип>` | показывать тип в мире |
| `/sc target <x> <y> <z>` / `/sc target clear` | своя точка |
| `/sc structures` / `/sc remove <id>` | найденные тобой / удалить ошибочную |
| `/sc add <тип> <чанкX> <чанкZ> [поворот]` | структура по стартовому чанку руками |
| `/sc seed` / `/sc seed <число>` / `/sc seed clear` | сид |
| `/sc crack` / `/sc cancel` | запустить долгий перебор / остановить |
| `/sc radius <блоки>` | радиус поиска |
| `/sc slime` | слайм-чанки вокруг тебя |
| `/sc visited` | скрывать посещённые |
| `/sc reset confirm` | стереть всё по этому миру |

## 7. Если что-то не так

* **`мало данных`**: найди ещё структуру, лучше храм, иглу, хижину или корабль.
* **`ни один сид не подходит`**: какая-то находка ошибочная. `/sc structures`, удали подозрительную
  через `/sc remove <id>` (чаще всего вписанная руками).
* **`биомы не сходятся`**: на сервере датапак с другой генерацией или изменённые соли структур.
  Если сервер прислал хэш сида, сид всё равно найдётся (`по хэшу, биомы другие`), но поиск по
  биомам и структурам в таком мире будет врать.
* **`хэш сида не пришёл`**: сервер его скрывает, мод подберёт биты по биомам, просто полетай.
* Всё сохраняется отдельно для каждого сервера.
