# End City Finder

Клиентский Fabric мод для Minecraft Java **26.2**. Находит все города края по паре-тройке
уже найденных городов и обсидиановым пилонам на главном острове, а потом показывает их:
лучами и подписями в мире, стрелкой к ближайшему городу, на карте и в чате.
Города с кораблями (элитры) подсвечиваются отдельно.

Работает на любом сервере: мод только читает чанки, которые клиент и так получил, и ничего не
отправляет на сервер.

Пошаговый гайд для игроков: **[docs/GUIDE.md](docs/GUIDE.md)**.

## Установка

1. Fabric Loader 0.20.1+ и Fabric API для 26.2.
2. Положить `endcityfinder-*.jar` в `mods`. Собранный jar лежит в артефактах GitHub Actions
   (workflow `build`), либо собрать самому: `./gradlew build`, файл в `build/libs/`. Нужна Java 25.

## Как пользоваться

1. **Пилоны.** Долети до центрального острова энда (хватит прорисовки ~10 чанков). Мод сам
   считает высоты всех 10 обсидиановых пилонов. Проверить: `/ecf pillars`.
2. **Города.** Найди хотя бы 2–3 города. Мод замечает их сам, когда чанки с городом прогрузились,
   и определяет стартовый чанк и поворот по нижнему ярусу главной башни. Если автоопределение
   не сработало, встань в нижнем зале главной башни и нажми `L` (или `/ecf add`).
   Если координаты известны заранее, их можно ввести руками:
   * `/ecf chunk <cx> <cz> [0|90|180|270]` точный стартовый чанк (чанк, в котором стоит
     нижний зал главной башни), поворот необязателен;
   * `/ecf add <x> <z>` примерные координаты основания, мод переберёт соседние чанки.
3. Солвер запускается сам. Статус виден сверху слева и в `/ecf status`. Перебор идёт в фоне
   на всех ядрах кроме одного и занимает секунды–десятки секунд.
4. После решения: лучи над городами, рамка города, отдельный маркер корабля, стрелка
   к ближайшему непосещённому городу на экране и в мире перед тобой. Посещённые города
   отмечаются сами, когда пролетаешь рядом.

Чем больше полетал, тем надёжнее: пустые прогруженные чанки и рельеф тоже используются для
отсева неверных вариантов, так что иногда хватает и двух городов.

Если сид мира известен (например, на своём сервере через `/seed`), можно сразу
`/ecf seed <число>`, тогда искать ничего не надо.

## Клавиши

* `J` карта энда (колесо зум, ЛКМ тащить, ПКМ по городу сделать целью)
* `K` маркеры в мире вкл/выкл
* `L` добавить город рядом

## Команды

| Команда | Что делает |
| --- | --- |
| `/ecf status` | что известно и что делает солвер |
| `/ecf add` / `/ecf add <x> <z>` | город рядом / по примерным координатам |
| `/ecf chunk <cx> <cz> [поворот]` | точный стартовый чанк города |
| `/ecf cities`, `/ecf remove <id>` | найденные города, удалить ошибочный |
| `/ecf pillars`, `/ecf pillar <0-9> <высота>` | пилоны, ручной ввод высоты |
| `/ecf list [n]` | ближайшие города с координатами (кликабельно) |
| `/ecf target <n>` / `/ecf target nearest` | выбрать цель для стрелки |
| `/ecf visited <n>` | отметить посещённым или снять отметку |
| `/ecf ships` | только города с кораблями: стрелка, маркеры, карта и список (повторно выключает) |
| `/ecf looted` | показывать или скрывать залутанные города (по умолчанию скрыты) |
| `/ecf party add/remove <ник>` | друг с модом: сид и залутанные города ходят автоматически |
| `/ecf share [ник]`, `/ecf accept` | отправить сид, соль и залутанные / принять присланный сид |
| `/ecf salt [число/reset]` | соль городов, если сервер её поменял (обычно вычисляется сама) |
| `/ecf markers`, `/ecf arrow`, `/ecf hud` | включить/выключить части интерфейса |
| `/ecf radius <блоки>` | радиус показа городов (по умолчанию 5000) |
| `/ecf seed <число>` / `/ecf seed clear` | задать известный сид |
| `/ecf map` | открыть карту |
| `/ecf reset confirm` | стереть все данные текущего мира |

Данные хранятся в `config/endcityfinder/worlds/<сервер или мир>.json`, настройки в
`config/endcityfinder/settings.json`.

## Как это работает

Весь энд (рельеф, биомы, города, пилоны) зависит только от младших 48 бит сида: везде
используется `LegacyRandomSource`.

* Пилоны: `new Random(seed).nextLong() & 0xFFFF` задаёт перестановку высот. Это биты 16..31
  второго состояния LCG, поэтому раскладка пилонов оставляет ровно 2^32 вариантов младших
  48 бит.
* Города: `random_spread` с шагом 20, разносом 11, солью 10387313 и треугольным распределением.
  Каждый город с точным чанком даёт около 6 бит, поворот ещё 2.
* Перебор 2^32 с ранним отсевом по городам, затем точная проверка каждого кандидата:
  настоящая генерация города (биом, высота рельефа ≥ 60), отсутствие городов в
  исследованных пустых чанках, совпадение рельефа.
* Корабли определяются портом логики `EndCityPieces` по габаритам шаблонов.
* Обмен с друзьями идёт обычными `/msg` с короткими токенами `ecf1:…#crc`, которые мод
  получателя прячет из чата. Серверный мод не нужен.

Ядро (`core`) не зависит от Minecraft. Тест `VanillaGroundTruthTest` сравнивает его с настоящим
генератором мира 26.2: расстановку, пилоны, рельеф, биомы, каждый кусок каждого города и
полный цикл взлома сида.

Клиентский тест `EndCityFinderGameTest` (workflow `build`, job `client-gametest`) запускает
настоящий клиент 26.2 и выделенный сервер с известным сидом: бот прилетает к пилонам, вводит один
город командой `/ecf chunk`, пролетает над тремя городами, а мод сам их находит, взламывает сид и
предсказывает остальные города; результат сверяется с правдой, скриншоты маркеров, карты и
команд выводятся в лог.

Подробное ТЗ: [docs/SPEC.md](docs/SPEC.md).

## Ограничения

* Нужны пилоны. Без них перебор занял бы дни.
* Если сервер на Spigot/Paper поменял соль городов (`seed-endcity` в `spigot.yml`), мод
  вычисляет её сам: сначала сид по пилонам, поворотам городов, биомам и рельефу, потом соль
  перебором 2^32 по позициям городов. Для этого нужно 3+ города с известным поворотом,
  для однозначной соли лучше 6–7.
* Датапаки, меняющие генерацию энда, ломают предсказания.
